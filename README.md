## 简介

《都市异想图鉴》把月亮计划三部曲（《脑叶公司》《废墟图书馆》《边狱巴士公司》）以及《扭曲侦探》《维利坦》《神奇实验室》等作品中的「心灵具象化」资料整合到一处，做成一本可以随身翻的图鉴。

它不只是一个资料库。除了查阅，你还可以听原声、抽一次卡、下一趟镜牢，或者自己动手往里面添一条异想体。

灵感来自《宝可梦》的全国图鉴——那种「一个世界的全部生物都在一册里」的感觉。

## 功能

| 模块 | 说明 |
|---|---|
| **图鉴** | 异想体、E.G.O 武器 / 护甲 / 饰品、扭曲、神备、考验、罪种及其衍生物 |
| **音乐** | 收录月亮计划作品中的原声，支持歌词显示与播放控制 |
| **指令生成器** | 按都市语汇生成指令文本 |
| **折射镜牢** | 简化版的镜像迷宫玩法：卡牌、事件、商店、战斗 |
| **镜像提取** | 抽卡模拟 |
| **DIY 编辑器** | 在软件内填写条目、导入图片与音频，打包成 `.ires` 资源包 |
| **DIY 加载器** | 读取 `.ires` 资源包，即时并入图鉴 |
| **收藏夹** | 把常看的条目收在一起 |
| **立绘与对话** | 主界面可更换立绘、编辑对话内容并保存为配置 |
| **多语言** | 内置翻译接口，可自行导入语言文件 |

## 平台与运行要求

| 项 | 要求 |
|---|---|
| 系统 | Windows 10 及以上；Android 8.0 及以上 |
| 分辨率 | 基准 648 × 1152（竖屏） |
| 内存 | 建议 2 GB 以上 |

## 安装与运行

**Windows**

1. 解压到任意目录
2. 双击 `IFA.exe` 运行

> 请**不要**放在 `C:\Program Files` 这类需要管理员权限的目录。
> 软件会把翻译文件、DIY 资源包写到 exe 同级目录，没有写权限时会失败。

**Android**

安装 APK 即可。首次使用 DIY 功能时需要授予存储权限。

## 版本号规则

版本号形如 `B.01.22.2`，四位，含义如下：

| 位 | 含义 |
|---|---|
| 第一位 | 阶段：`A` Alpha 测试版 · `B` Beta 测试版 · `P` 预览版 · `R` 正式版 |
| 第二位 | 大更新 |
| 第三位 | 小更新 |
| 第四位 | 补丁优化 |

主界面左下角会显示当前版本号与运行平台，反馈问题时请一并提供。

## 发行形态

同一份工程可产出不同形态的发行版：

- **完整版**：全部功能与全部资源
- **小游戏版**：仅保留小游戏入口，适合体积受限的渠道

形态切换通过 `mode_config_file/` 下的标记文件控制，无需维护两套工程。

## 项目结构

```
project.godot        工程配置
screen/              界面场景（主界面、图鉴页、设置、关于等）
script/              逻辑脚本（全局状态、数据装配、加载、DIY）
little_game/         折射镜牢小游戏（战斗、事件、卡牌、敌人）
res/                 内置数据（.tres 资源、字体、主题）
res_pack/            内置异想体资源包
img/ img2/           界面与立绘素材
mus/                 音乐资源
translations/        语言文件
addons/              第三方插件
mode_config_file/    发行形态标记
```

**数据驱动**：图鉴条目以 Godot `Resource` 形式存储（`.tres`），界面按类型分别读取；DIY 资源包则使用 CSV + 资源文件，打包为 `.ires` 后在运行时装配成同样的 Resource。
